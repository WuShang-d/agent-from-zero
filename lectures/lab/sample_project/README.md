# 贯穿课程的小项目

任务：“修复 `stats.py` 的 `average_duration`，让它返回真实平均值，并运行测试解释改动。”当前实现故意使用整数除法；对 `[1, 2]` 返回 `1`，而期望为 `1.5`。

在这个目录中运行：

```bash
python3 -m unittest -v test_stats.py
```

**初始测试应失败**，这是课程固定的基线，不是 Agent 程序故障。第 6–10 课只允许读取它；完成第 11 课的权限和执行边界后，才让 Agent 在隔离的副本中修复。建议每次实验从干净副本开始，记录文件内容摘要、测试输出与最终 diff。它是任务环境，不是预写好的 Agent。
